# Team Portfolio Platform — Git/GitHub Workflow

## პროექტის დასახელება

Team Portfolio Platform — გუნდური პორტფოლიოს ვებგვერდი

## პროექტის აღწერა

პროექტის მიზანი იყო HTML-ისა და CSS-ის გამოყენებით გუნდური პორტფოლიოს შექმნა და Git/GitHub-ის საშუალებით ინდივიდუალური ნამუშევრების ერთ პროექტში გაერთიანება.

## გუნდის წევრები და როლები

- **სტუდენტი 1 — ნიკა ჯინჭარაძე (Repo Owner / Team Lead)**  
  Branch: `feature/student1-card`
- **სტუდენტი 2 — ლერი ქარცივაძე**  
  Branch: `feature/student2-card`
- **სტუდენტი 3 — რიკარდო ლაზიშვილი**  
  Branch: `feature/student3-card`

**მთავარი ბრენჩი:** `main`

## გუნდური მუშაობის პროცესი

ნიკა ჯინჭარაძემ შექმნა GitHub-ის რეპოზიტორია და `main` ბრენჩზე განათავსა პროექტის საწყისი HTML და CSS ფაილები.

შემდეგ სამივე სტუდენტმა საკუთარ ბრენჩზე დამოუკიდებლად იმუშავა, შეიტანა ინდივიდუალური ცვლილებები და ატვირთა GitHub-ზე `commit` და `push` ბრძანებების გამოყენებით.

Pull Request-ების გაერთიანების თანმიმდევრობა იყო:

1. რიკარდო ლაზიშვილი — PR #1
2. ლერი ქარცივაძე — PR #3
3. ნიკა ჯინჭარაძე — PR #2

## Merge Conflict-ის ანგარიში

### კონფლიქტური ფაილები

- `index.html`
- `style.css`

### კონფლიქტის მიზეზი

რიკარდო ლაზიშვილმა პირველმა გააერთიანა თავისი ცვლილებები `main` ბრენჩში. მოგვიანებით, ნიკა ჯინჭარაძის ინდივიდუალური ბრენჩის გაერთიანებისას წარმოიქმნა Merge Conflict.

კონფლიქტი გამოწვეული იყო ორივე სტუდენტის მიერ ერთსა და იმავე კოდის მონაკვეთებში განხორციელებული განსხვავებული ცვლილებებით.

`index.html`-ში განსხვავდებოდა მთავარი სათაური, აღწერითი ტექსტი და პროფილების განლაგება. `style.css`-ში კი — ძირითადი ფერები და სექციების ფონის მნიშვნელობები.

### კონფლიქტის მოგვარების გზა

კონფლიქტი მოვაგვარეთ GitHub-ის **Resolve conflicts** რედაქტორში.

1. შევადარეთ კონფლიქტური HTML და CSS კოდები.
2. `index.html`-ში დავტოვეთ საერთო სათაური „გაიცანით ჩვენი გუნდი“ და შევინარჩუნეთ სამივე სტუდენტის პროფილის ბარათი.
3. `style.css`-ში ავირჩიეთ ნიკას მწვანე ფერი (`#216b62`) და შესაბამისი ფონის ფერები (`#e5f5f0`).
4. წავშალეთ კონფლიქტის ნიშნები (`<<<<<<<`, `=======`, `>>>>>>>`) და გავასწორეთ კოდის სტრუქტურა.
5. ცვლილებები შევინახეთ **Mark as resolved → Commit merge** მოქმედებებით.
6. საბოლოოდ PR #2 წარმატებით გავაერთიანეთ `main` ბრენჩში.

## საბოლოო შედეგი

გუნდური თანამშრომლობის შედეგად სამივე სტუდენტის ინდივიდუალური ნამუშევარი გაერთიანდა ერთ პროექტში.

საბოლოო ვებგვერდზე შენარჩუნებულია სამივე პროფილი, ქართული ტექსტები, ერთიანი დიზაინი და ადაპტური განლაგება.
